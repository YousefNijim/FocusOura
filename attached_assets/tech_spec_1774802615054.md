FocusOura – Technical Specification
1. Project Overview

FocusOura is a mobile-first productivity SaaS application designed to help students achieve deep focus through an event-driven study system that combines behavioral tracking, biological growth visualization, gamification, and AI-driven motivation.

The system is designed to be scalable, secure, and maintainable, following clean architectural principles.

5. Data Handling Principles

No direct writes to Firestore from UI

All writes go through:

Application services

Cloud Functions (when critical)

Sessions are event-based, not single records

Wallet operations must be atomic

6. Session Design Principles

A focus session is a state machine

Possible states:

Initialized

Started

Warning

Completed

Aborted

Each state change produces an event

Events are persisted and used for:

Analytics

Growth calculation

AI analysis

7. AI Integration Rules

AI is treated as an external system

No core logic depends on AI availability

AI responses are:

Optional

Post-processed

Stored as insights, not facts

8. Security & Multi-Tenancy

Every data entity includes:

userId

tenantId

Firestore rules enforce:

User data isolation

Tenant boundaries

No cross-user access without explicit logic

9. Coding Principles & Constraints

Single responsibility per service

No God classes

Explicit naming (no abbreviations)

Prefer immutability in domain entities

Fail-safe defaults (especially for AI)
